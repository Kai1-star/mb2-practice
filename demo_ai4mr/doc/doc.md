## 对齐坐标系

基准姿势

板子屏幕朝上平放在桌上，USB 口朝向远离你的方向。从上往下看时：

A 键在你左手边
B 键在你右手边
金手指那条边靠近你

测 5 次，每次只抬起一条边，大约 30°
#	动作	看哪个数	你的结果	
0	不动，平放	az	     -1000
1	抬高 B 键边（右）ax    变负	 
2	抬高 A 键边（左）ax   变正
3	抬高 USB 边（远处）	ay  变负
4	抬高 金手指边（近处）ay  变正


轴	我们的实测（加速度计，解释 A）
x	指向 A 键 ✓
y	指向金手指 ✓
z	从背面穿出 ✓

## heading函数 


``` let (mut east, mut south) = (ax * X_SIGN, ay * Y_SIGN);   // X_SIGN = 1, Y_SIGN = -1 ```
把现实的坐标转换到屏幕的坐标

```
if east.abs() < 150 && south.abs() < 150 { 
    return Dir::Flat;
} 
```

.abs()是取绝对值，如果太平了，就不判断方向 

```
if east.abs() >= south.abs() {      // 左右分量更大
    if east > 0 { Dir::E } else { Dir::W }
} else if south > 0 {               // 上下分量更大，且朝下
    Dir::S
} else {                            // 上下分量更大，且朝上
    Dir::N
}

```
先比较左右分量，然后比较前后分量，最后得出该向那个方向偏。
